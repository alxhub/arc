# ARC-TERM-01

ARC-TERM-01 closes the end of an ARC backbone run. It terminates both the CAN connection used for commands and status and the DCC timing connection used by track drivers. A run uses a terminator at each end; the nodes along it pass the connections through.

The board has one backbone jack. A power light shows whether the backbone supply reaches this end of the run, and measurement points give installers a place to check the supply and both signal pairs.
